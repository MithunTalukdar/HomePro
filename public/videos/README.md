# Realistic Live-Action Service Videos

Please place your **real-life, live-action footage** here. 
The system requires realistic, commercial-quality MP4 videos of real professionals working in real home environments. 
**DO NOT use cartoons, animations, illustrations, or 3D character videos.**

Add the following exact filenames to this directory to power the Hero Video Slider:

- `fan-repair.mp4` (Showing a real technician repairing or servicing a ceiling fan/home fan)
- `ac-repair.mp4` (Showing a real HVAC/AC technician servicing an air conditioner)
- `refrigerator-repair.mp4` (Showing a real technician repairing or inspecting a refrigerator)
- `electrician-service.mp4` (Showing a real professional electrician doing electrical work)
- `home-cleaning.mp4` (Showing a real professional cleaning team working inside a modern home)

The slider will automatically loop through these live-action videos in order.
